Command Explorer

Interactive Commands

Both standard prefix commands and Discord slash commands are supported.

>play [song/url]
Play any song or playlist from YouTube, Spotify, or Soundcloud.
>skip
Skip the currently playing track in queue instantly.
>stop
Stop audio playback and clear the remaining queue.
>volume [0-150]
Adjust server playback volume from 0% up to 150%.
>bassboost
Apply deep low-end frequency boost to audio output.
>8d
Enable 8D spatial audio rotation for immersive listening.
>nightcore
Speed up track tempo and pitch for nightcore effect.
>clearfilters
Reset all active equalizer and audio processing filters.
>playlist create [name]
Create custom playlist saved in the bot database.
>playlist playcode
Load shared public playlist by code in your voice channel.
>247
Toggle 24/7 mode so the bot stays connected in VC non-stop.
>djrole [@Role]
Set or clear required DJ role for playback controls.
